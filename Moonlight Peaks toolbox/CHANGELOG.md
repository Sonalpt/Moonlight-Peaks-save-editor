# Changelog

All versions target Moonlight Peaks 1.1.30 (build ID `BBA199B4CD2A58D2`).

## 0.5.0

- Pause time, and time speed (×½, ×1, ×2).
- "Finish constructions tonight": constructions in progress get one day
  left, so the game finishes them overnight with its own events.
- Diagnostics show the time speed and each construction's days left.

## 0.4.0

- Backpack and Storage pages with item names; change any stack's amount.
- Give items (everyday categories only) to the backpack or storage.

## 0.3.2

- Removed "Hide game HUD": it needs a game signal that an overlay can't
  send.

## 0.3.1

- Fixed coins, one-hit break and machines, which refused to run in 0.3.0.
  Objects are now checked by their class name.
- Refill animal produce.
- Diagnostics page.

## 0.3.0

- Coins, jump forward in time, one-hit trees and rocks, finish all machines.

## 0.2.1

- Developer switches: any tool breaks anything, animals always drop
  produce, repeatable daily item drops. Witch circles and Nokturna auto-win
  were removed to protect game progression.

## 0.1.0

- First overlay: infinite energy and infinite mana.
